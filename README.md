# 湖表工坊 · 湖表分区演化与小文件归并平台

面向湖表目录登记、表结构演进、分区规划与演化、小文件归并、快照与时间旅行、入湖水位推进、压实调度、统计画像、隔离区处置、消费视图发布与存储分层的湖表治理平台。

这是一个前后端分离的管理平台：前端 Vue 3 + Vite + TypeScript，后端 FastAPI（Python）。
两边各自独立启动，前端 dev server 已关掉自动打开页面，启动后按终端打印的地址手工打开。

## 目录结构

```text
.
├── frontend/                 Vue 3 + Vite + TypeScript 前端
│   ├── src/views/WorkbenchView.vue|tsx  全部模块共享工作台
│   ├── src/data/modules.ts              18个业务模块配置
│   ├── src/api/              统一请求封装
│   └── vite.config.ts        dev server 配置（open: false）
├── backend/                  FastAPI（Python） 后端
│   ├── app/routers/resource.py  通用查询/导出/登记/动作接口
│   ├── app/services/<key>.py    每个模块独立领域逻辑
│   ├── app/services/base.py     共享服务骨架
│   └── app/store.py          内存数据仓库与示例数据
├── .gitignore
└── docker-compose.yml
```

## 启动

### 后端

```bash
cd backend
python3 -m venv .venv && .venv/bin/pip install -r requirements.txt
./run.sh
```

健康检查：`curl http://127.0.0.1:8001/api/health`

### 前端

```bash
cd frontend
npm ci
npm run dev
```

前端默认监听 `http://127.0.0.1:5174/`，dev server 不会自动打开浏览器，
需要自己访问。`/api` 由 vite 代理到后端 `http://127.0.0.1:8001`。

## 约定

- 全部模块共享`frontend/src/views/WorkbenchView.vue|tsx`和一套资源路由。
- 每个模块仍保留独立`backend/app/services/<模块>.py`；纯前端保留
  `frontend/src/domain/<模块>.ts`，用于承载真实业务差异并维持36题位容量。
- 列表接口统一返回 `{ items, total, page, size }`，动作接口统一返回 `{ ok, message }`。
- 状态流转只允许在 `app/services` 里改，路由层不做业务判断。

## 列画像与压实候选

列统计新增「按筛定批次计算列画像」的入口，落到 `/column_stat/profiles` 页面；
压实作业则通过 `/compact_job/candidates` 领取候选。核心语义：

- **筛选维度**：结构版本、来源系统、显式批次号；样本清单记录每个批次的版本、
  修订号、行数与校验值。
- **V1 数值 vs V2 文本**：结构声明决定取值口径。V1 的 `amount` 是数值，`0` 与 `5`
  都进入区间，能看到 `0 ~ 5`；V2 同名字段声明为文本，文本取值只计基数，不进入
  `min/max`，因此查询 V1 时不会把 V2 的文本混进数值计算。
- **空值与缺列分开核对**：缺列指行中根本没有该列，空值指列存在但值为空，
  两者分别计数，并由 `verification.checks` 给出行数闭合、口径说明等核对项。
- **湖表独立计数**：`ods_payment` 里同叫 `amount` 的字段单独成画像，指纹与样本互不串扰。
- **画像原件**：画像一旦生成即不可变，保存行级样本快照与指纹；迟到或事后补数
  不会改写已领取计划所依赖的原件，`recompute` 可从原件复算并比对指纹。
- **旧版补数更正并发**：补数更正批次行会推进修订号。已领取计划记录当时消费的
  画像版本、来源批次与修订号，可查询判断结果与样本漂移；待领取计划重新比对
  行数门槛，不满足则转为「已失效」，并在 `recompare_history` 留下前后结论。
- **详情页核对**：`/api/column_stat/profiles/{id}` 返回样本清单与关联压实候选，
  候选记录关联采用的画像版本和来源批次，供从画像详情页逐条核对。
